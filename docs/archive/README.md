lote de herramientas e informes de auditoría puntuales. Se conservan como
referencia, pero no describen el estado actual del sistema. La documentación
vigente está en `docs/architecture.md`, `docs/api-contract.md`,
`docs/migration-playbook.md` y el `README.md` de la raíz.
